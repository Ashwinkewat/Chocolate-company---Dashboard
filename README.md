# 🍫 Awesome Chocolates — Power BI Sales Dashboard

## 📌 Project Overview

This project is an interactive sales analytics dashboard built using Microsoft Power BI to analyze sales performance for a chocolate company. It provides a consolidated view of key business metrics, helping users explore sales, profitability, shipment volumes, product performance, and salesperson performance.

The dashboard is designed to make business data easier to understand through visualizations, summary metrics, and interactive filtering.

## 🎯 Project Objectives

- Monitor overall sales and profitability.
- Analyze shipment volumes and boxes sold.
- Compare sales performance across salespeople.
- Explore product-level performance.
- Examine business performance across geographical regions.
- Support data-driven business decision-making.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** — Dashboard development and data visualization
- **DAX** — Measures and calculations
- **Power Query** — Data preparation, where applicable

## 📊 Key Performance Indicators (KPIs)

The dashboard includes measures for:

- **Total Sales** — Overall sales value
- **Profit %** — Profitability percentage
- **Total Boxes** — Number of boxes sold or recorded
- **Total Shipments** — Shipment volume

## 🔍 Dashboard Features

- Sales and profitability analysis
- Salesperson performance comparison
- Product-level analysis
- Geographical filtering and analysis
- Shipment and box-volume reporting
- Interactive visualizations for exploring business performance
